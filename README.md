
# Week 3 - Task 1: Handling Checked Exceptions

## Description
This Java program reads data from a text file and handles
file-related exceptions using try-catch blocks.

## Concepts Used
- Checked Exceptions
- File I/O
- FileReader
- BufferedReader
- FileNotFoundException
- IOException
- Try-with-resources

## How to Run
1. Open the project in IntelliJ IDEA.
2. Make sure sample.txt exists in the project folder.
3. Run FileExceptionDemo.java.
4. Rename or remove sample.txt to test the error message.

## Expected Behavior
The program displays the contents of the file when it exists.
It displays an appropriate error message when the file
cannot be found or another I/O error occurs.
